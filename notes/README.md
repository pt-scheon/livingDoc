# notes/

Shared notes between the shop owner, the developer and coding agents (Gemini, Claude, Copilot).

- `CHANGELOG.md`: every change, newest first. Add yours at the top.
- `ARCHITECTURE.md`: module map, routes, tables, conventions.
- `FEEDBACK.md`: the owner's suggestions to the developer, generated from the app. Do not edit by hand.

Refresh the feedback file: `python scripts/export_feedback.py` (or `make notes`).
